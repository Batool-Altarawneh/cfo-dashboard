# 💰 CFO Financial KPI Dashboard

> Full-stack financial analytics platform built for a fictional
> Canadian B2B technology company — NorthStar Analytics Inc.

## What This Is
A production-grade financial reporting and forecasting platform combining:
- Automated ETL pipeline (Python, PostgreSQL, Airflow)
- Three ML models (revenue forecasting, anomaly detection, budget prediction)
- Executive Power BI report (CFO-facing, descriptive analytics)
- Streamlit ML dashboard (analyst-facing, predictive analytics)

## Tech Stack
Python · PostgreSQL · Apache Airflow · Power BI ·
Streamlit · Docker · GitHub Actions
